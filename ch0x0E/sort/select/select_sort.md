# 선택 정렬
## 선택 정렬 알고리즘에 대해 설명해주세요
- 오름차순 정렬 기준으로 설명드리겠습니다.
- 배열이 주어질 경우, 주어진 배열에서 최솟값을 찾습니다.
- 이후 맨 앞자리와 최솟값을 스왑합니다.
- 맨앞자리를 제외한 나머지 값 중에서 최소값을 찾아서 위 방법을 반복하게 됩니다.

## 손코딩 이후 해당 로직의 시간복잡도를 설명해주세요
[구현은 SelectSort.java 참고](SelectSort.java)
- 선택 정렬은 버블 정렬처럼 상위 반복문을 돌 때마다 1자리는 정렬이 완료된 상태가 됩니다.
- 따라서 (n - 1) + (n - 2) + ... + 2 + 1 = (n)(n - 1) / 2 의 시행 횟수로 최악의 경우 O(N ^ 2)의 시간 복잡도를 보입니다.
- 하지만 이미 정렬된 상태인 최선의 경우에도 정렬 상태를 저장하지 않기 때문에 O(N ^ 2)의 시간 복잡도를 보이게 됩니다.

## 선택 정렬은 안정, 불안정 정렬 중 어디에 해당하는지 설명해주세요
- 선택 정렬은 알고리즘 상 주어진 범위에서 최소값을 찾아서 가장 앞으로 위치시키게 됩니다.
- 이때 중복된 값은 고려하지 않기 때문에 입력값 순서가 보장되지 않을 수 있습니다.
