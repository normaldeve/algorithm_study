# 버블 정렬

## 버블 정렬를 설명해주세요
- 오름차순 정렬 기준으로 설명드리겠습니다.
- 크기가 N인 배열이 주어질 때, 인접한 데이터끼리 크기를 비교하게 됩니다.
- 이때 i 번째 데이터와 i + 1 번째 데이터 비교시 i 번째 데이터의 크기가 더 크다면 i + 1 번째 데이터와 자리를 스왑하게 됩니다.
- 이 과정을 배열이 모두 정렬될 때까지 반복합니다.

## 손코딩으로 구현 후 시간 복잡도를 설명해주세요
[구현은 BubbleSort.java 참고](./BubbleSort.java)
- 구버전과 신버전으로 나누어 설명드리겠습니다.
- 구버전 경우 정렬 상태를 확인하지 않고 반복문을 2번 돌게 되면서 O(N ^ 2)의 시간복잡도를 보입니다.
- 구버전 경우 이미 정렬된 배열이더라도, 시간 복잡도는 O(N ^ 2)이며, 최악의 경우더라도 O(N ^ 2)의 시간 복잡도를 보이게 됩니다.
- 하지만 신버전 경우 swap 변수를 통해 인접한 데이터가 스왑되었는지를 체크하게 됩니다.
- 따라서 최악의 경우 O(N ^ 2)의 시간 복잡도를 보이지만, 이미 정렬된 배열의 경우 O(N)의 시간 복잡도를 보이게 됩니다.
